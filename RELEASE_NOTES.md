## 🚀 Как запустить приложение

```bash
# 1. Перейти в папку проекта
cd veloraz-demo

# 2. Установить зависимости (если не установлены)
npm install

# 3. Запустить Expo
npx expo start --tunnel

# 4. Отсканировать QR-код
# Android: Используйте Expo Go
# iOS: Используйте встроенную камеру или Expo Go
```
