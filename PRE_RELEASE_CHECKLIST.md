### 📋 Перед финальной отправкой

1. **App Store (iOS)**
   ```bash
   # Обновить версию в app.json
   "version": "1.0.0"
   
   # Выполнить build
   eas build --platform ios
   
   # Отправить в TestFlight для тестирования
   # Затем отправить на review
   ```

2. **Play Store (Android)**
   ```bash
   # Обновить версию в app.json
   "version": "1.0.0"
   
   # Выполнить build
   eas build --platform android
   
   # Отправить для review
   ```
